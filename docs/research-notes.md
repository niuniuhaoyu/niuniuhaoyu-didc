## 1. 设定

- **两期**面板，`t ∈ {0, 1}`；`n` 个单位 `i`。
- **运行变量 `Z_i`（本文假设时不变）**，cutoff `z_0`。
- **关注的处理** `D_{i,1} = 1{Z_i ≥ z_0, t = 1}`。
- **混淆政策（confounder）** `D_{i,0} = 1{Z_i ≥ z_0, t ≥ 0}`——在处理之前就存在、且用**同一个** cutoff 分配。这是 DiDC 存在的理由：它使标准 RDD 的连续性假设失效。
- 潜在结果 `Y_{i,t}(d_0, d_1)`，`(d_0,d_1) ∈ {0,1}²`。
- 观测方程（式 1–2）：
  - `Y_{i,1} = [Y(1,1)D_0 + Y(0,1)(1−D_0)]D_1 + [Y(1,0)D_0 + Y(0,0)(1−D_0)](1−D_1)`
  - `Y_{i,0} = Y_{i,0}(1,0)D_{i,0} + Y_{i,0}(0,0)(1−D_{i,0})`

## 2. 识别假设（逐条照抄）

| 编号 | 名称 | 内容 |
|---|---|---|
| A1 | Continuity | 所有潜在结果在 `Z = z_0` 连续：`lim_{ε→0}E[Y_{it}(d_0,d_1)\|Z=z_0+ε] = lim_{ε→0}E[...\|Z=z_0−ε]`。（**只要求连续，不要求跳跃为 0**——混淆政策的跳跃被 A4 处理掉） |
| A2 | Random assignment at cutoff | `Y_{i,t}(d_0,d_1) ⊥ (D_{i,0},D_{i,1}) \| Z = z_0` |
| A3 | Sharp discontinuities | `D_0^+ = D_1^+ = 1`，`D_0^− = D_1^− = 0`（完全遵从） |
| A4 | **Time-invariance of confounding effects** | `E[Y_{i,0}(1,0)−Y_{i,0}(0,0)\|Z=z_0] = E[Y_{i,1}(1,0)−Y_{i,1}(0,0)\|Z=z_0]`——混淆效应随时间不变。**这是 DiDC 的核心假设，也是最脆弱的一条。** |
| A5 | No-interaction | `τ_c = τ_uc`，即关注处理与混淆政策不交互（可加可分） |
| A4′ | Multiplicative effects（放宽 A5） | `E[Y_1(1,1)−Y_1(0,0)] = E[Y_1(0,1)−Y_1(0,0)]·E[Y_1(1,0)−Y_1(0,0)]` |
| A6 | Bounded variations（部分识别用） | `\|E[Y_{i,1}(1,0)−Y_{i,0}(1,0)\|Z=z]\| ≤ c_1` 且 `\|E[Y_{i,1}(1,0)−Y_{i,1}(0,0)\|z_0] − E[Y_{i,0}(1,0)−Y_{i,0}(0,0)\|z_0]\| ≤ c_2` |
| A7 | Bounded outcomes（部分识别用） | `y^{min} ≤ Y_{i,t}(d_0,d_1) ≤ y^{max}` |
| A8 | Complementarity（supermodularity） | `Y_{i,1}(1,0)+Y_{i,1}(0,1) ≤ Y_{i,1}(1,1)+Y_{i,1}(0,0)` |
| A9 | Substitutability（submodularity） | `Y_{i,t}(1,0)+Y_{i,t}(0,1) ≥ Y_{i,t}(1,1)+Y_{i,t}(0,0)` |

## 3. 估计量与识别结果

三个参数：

| 参数 | 定义 | 含义 |
|---|---|---|
| `τ_c` | `E[Y_{i,1}(1,1) − Y_{i,1}(1,0) \| Z_i = z_0]` | cutoff 处**暴露于混淆政策**者的处理效应 |
| `τ_uc` | `E[Y_{i,1}(0,1) − Y_{i,1}(0,0) \| Z_i = z_0]` | cutoff 处**未暴露于混淆政策**者的处理效应 |
| `τ^DiDC` | `τ_1^RD − τ_0^RD`，其中 `τ_t^RD = Y_t^+ − Y_t^−` | DiDC 估计量 |

**Lemma 1（关键实现依据）**：在 A1–A3 下，

```
τ^DiDC = τ_1^RD − τ_0^RD = lim_{ε→0} E[ΔY_i | Z_i = z_0+ε] − lim_{ε→0} E[ΔY_i | Z_i = z_0−ε]
```

即 **「RDD 之差」= 「差分之 RDD」**。→ **实现上只需对 ΔY 跑一次 RDD**，不必分别估两期再相减。这是本包的计算核心。

**Lemma 2（Grembi et al. 2016）**：在 A1–A4 下，`τ^DiDC = τ_c`。

**Corollary 1**：在 A1–A5 下，`τ^DiDC = E[Y_{i,1}(d_0,1) − Y_{i,1}(d_0,0) | Z_i = z_0]`（更一般的效应）。

**Lemma 3（A4′ 版本）**：`τ^DiDC / τ_0^RD + 1 = τ_uc`。论文自述 "our future work will focus on the properties"，**v1 不实现**。

## 4. 估计（§3）

### 4.1 局部多项式

定义 `ΔY_i = Y_{i,1} − Y_{i,0}`，`Δμ(z) = E[ΔY_i | Z_i = z]`。

```
τ^DiDC = Δμ_+ − Δμ_− ,   Δμ_+ = lim_{z→0+} Δμ(z),  Δμ_− = lim_{z→0−} Δμ(z)
```

`p` 阶局部多项式、`ν` 阶导数（`ν ≤ p`，v1 只用 `ν = 0`）：

```
δ̂_{ΔY+,p}(h) = argmin_{δ∈R^{p+1}} Σ_i 1{Z_i ≥ 0}(ΔY_i − r_p(Z_i)'δ)² K_h(Z_i)
δ̂_{ΔY−,p}(h) = argmin_{δ∈R^{p+1}} Σ_i 1{Z_i <  0}(ΔY_i − r_p(Z_i)'δ)² K_h(Z_i)
Δμ̂_{+}^{(ν)}(h) = ν! e_ν' δ̂_{ΔY+,p}(h) ,   r_p(x) = [1 x … x^p]' ,   K_h(u) = K(u/h)/h
```

→ **与 CCT(2014) 对 `(ΔY, Z)` 做标准 RD 完全同构**。这是验证锚点（见 §8）。

### 4.2 带宽

`Lemma 4`：MSE-最优带宽

```
h_{n,ν,p}^{MSE} = ( (1+2ν) V_{ν,p} / (2 n (1+p−ν) B²_{ν,p,p+1,s}) )^{1/(2p+3)}
```

v1 实现：**直接委托 CCT 的 plug-in / 双向（`mserd`、`msetwo`）选择器**，不自行推导。理由——论文本身即用 `rdrobust` 选带宽；自行实现只会引入不可验证的差异。

### 4.3 偏误校正与稳健置信区间（§3.2.1、Theorem 1）

- 用 **`q > p`** 阶局部多项式和带宽 `b`（`b_n = h^{MSE}_{n,p+1,q,ν+p+1}`）估计 `p+1` 阶导数，得 `B̂_{ν,p,q}(h,b)`；
- 偏误校正估计量 `τ̂^{bc} = τ̂_{ν,p}(h) − h^{p+1−ν} B̂_{ν,p,q}(h,b)`；
- 稳健 CI 用 CCT 的 `V^{bc}`（含估计偏误带来的额外方差）：

```
CI_{ν,p,q}(h,b) = [ τ̂^{bc} ± Φ^{-1}_{1−α/2} sqrt(V^{bc}) ]
```

**Lemma 5（本包 README 的核心卖点）**：`B[τ̂^DiDC] = B[τ̂_1^RD] − B[τ̂_0^RD]`。→ 加进处理前一期数据可以**抵消偏误**，即使在标准 RDD 有效的情形下也可能降偏。

## 5. 有效性检验（§4）

### 5.1 混淆效应是否时不变（§4.1）

用**处理前的多个期**做 **stacked RD**：

```
Y_i = α_i + Σ_{k=1}^{K} [ β_{−k}(Z_i − z_0) + θ_{−k} D_i (Z_i − z_0) ] T_{−k} + ε_i      (式 7)
```

`T_{−k}` 为期别哑变量，`D_i = 1{Z_i ≥ z_0}`。检验：

```
H_0 : θ_0 = θ_{−1} = … = θ_{−K}
```

**Wald 检验**即可。拒绝 → DiDC 不适用。
实现注意：论文 Appendix D.1 的模拟结论是「**任何数据驱动的、对该 RD 最优的带宽都行**」，故 v1 允许用户以 `bw()` 指定或用各期 CCT 带宽的最小值。

### 5.2 潜在结果函数形式是否时不变（§4.2）

两样本 **KS 型检验**（改造自 Whang 2001 的条件矩检验）。需要**处理前至少两期**（`t ∈ {−1, 0, 1}`）。

以逼近函数向量 `p^K(·)`（v1 用多项式基）在每个期、每侧分别做最小二乘：`γ̂_t^+`、`γ̂_t^−`。检验统计量：

```
KS_+ = sup_{z ∈ S+(Z)} (1/sqrt(n+)) Σ_{i: Z_i ≥ z_0} | (p^K(Z_i)'γ̂_0^+ − p^K(Z_i)'γ̂_{−1}^+) 1{Z_i ≤ z} |
KS_− = sup_{z ∈ S−(Z)} (1/sqrt(n−)) Σ_{i: Z_i <  z_0} | (p^K(Z_i)'γ̂_0^− − p^K(Z_i)'γ̂_{−1}^−) 1{Z_i ≤ z} |
```

- `n+ = Σ 1{Z_i ≥ z_0}`，`n− = Σ 1{Z_i < z_0}`。
- p 值与 CI 用 **recentered bootstrap**（Hall & Horowitz 1996），**在 bootstrap 分布上施加原假设**（回归时把两期的共同成分扣掉）。Appendix F 给出 bootstrap 一致性的条件。
- ⚠️ **原论文 KS_− 的求和下标印成了 `Z_i ≥ z_0`，与 `S−(Z)` 的定义自相矛盾，应为 `Z_i < z_0`。** 实现按后者（见 §9）。

## 6. 部分识别与敏感度分析（§5）

### 6.1 有界变异（A6，`Lemma 6`）

```
τ_c^LB = max{ ΔY^+ − c_1 , (ΔY^+ − ΔY^−) − c_2 }
τ_c^UB = min{ ΔY^+ + c_1 , (ΔY^+ − ΔY^−) + c_2 }
```

其中 `ΔY^+ = lim_{z→z_0+} E[ΔY|Z=z]`，`ΔY^− = lim_{z→z_0−} E[ΔY|Z=z]`，故 `ΔY^+ − ΔY^− = τ^DiDC`。

**推导（用于自检，非论文原文）**：
- 右侧单位 `D_0=D_1=1` → `ΔY^+ = E[Y_1(1,1) − Y_0(1,0)]`；`τ_c = E[Y_1(1,1) − Y_1(1,0)]`
  → `ΔY^+ − τ_c = E[Y_1(1,0) − Y_0(1,0)]`，即「有混淆者的潜在结果的**时间趋势**」，被 `c_1` 界住。
- `τ_c − τ^DiDC = E[Y_1(1,0)−Y_1(0,0)] − E[Y_0(1,0)−Y_0(0,0)]`，即「**混淆效应的时间漂移**」，被 `c_2` 界住。
- 结论：`c_1` = 混淆者潜在结果的时间趋势上界；`c_2` = 混淆效应自身的时间漂移上界。**两个参数经济含义不同，不能混用。**

估计：把 §4 的局部多项式估计量代入 max/min。**breakdown value**（结论翻转的最小 `c_1, c_2`）可直接读出。

**推断**：极限过程非 Gaussian，收敛率 `sqrt(n·min{h,b})`；max/min 映射**方向可导但不可微**，标准 bootstrap 失效 → 论文推荐 **Fang & Santos (2018) §3.2.1 的 bootstrap**。
⚠️ 但论文脚注也指出：**当 min/max 内部各项不相等时映射全可微，标准 bootstrap 就有效**。v1 实现时须显式检测是否处于「kink」，并对 kink 情形给出警告。

### 6.2 模性（A7–A9，`Lemma 7`–`Lemma 8`）

```
A8 互补： τ_c ∈ [y^min − Y_1^−, y^max − y^min] ，  τ_uc ∈ [y^min − y^max, Y_1^+ − y^min]
A9 替代： τ_c ∈ [y^min − y^max, y^max − Y_1^−] ，  τ_uc ∈ [Y_1^+ − y^max, y^max − y^min]
```

`Y_1^+ = lim_{z→0+} Y_1`，`Y_1^− = lim_{z→0−} Y_1`（**第一期**结果的左右极限，不是 ΔY）。

### 6.3 合并（`Lemma 9`–`Lemma 10`）

有界变异 + 模性可收紧边界（`Lemma 9` 用 A8，`Lemma 10` 用 A9）。对 `τ_c` 两侧都收紧；对 `τ_uc` 只有一侧收紧，另一侧仍是 worst-case。

## 8. 实证案例（§7，用于示例数据与端到端测试）

Grembi, Nannicini & Troiano (2016)，意大利市政财政规则放松：

- 处理：2001 年财政规则放松；cutoff = **人口 5000**（`< 5000` 为处理组——**注意方向：左上转移**）。
- 混淆政策：市长薪资也以 5000 为界。
- 2×2 设计：`t = 0` → 2000 年，`t = 1` → 2001 年。
- 三个结果：`Deficit`、`Fiscal Gap`、`Taxes`。
- 论文的 stacked-RD Wald 检验（1998/1999/2000）结果：**Taxes 拒绝**时不变（F = 3.010，p = 0.046），Deficit（F = 0.294，p = 0.745）与 Fiscal balance（F = 0.182，p = 0.833）**不拒绝**。
- KS 检验：Taxes 与 Fiscal balance 双侧 p ≈ 0.001（强拒绝）；Deficit 左侧 p = 0.266、右侧 p = 0.001。
- 数据来源需另寻（Grembi et al. 的 replication data）；若不可得，v1 用模拟数据 + 公开可得的替代 RD 数据做端到端示例，并在 README 注明。

```
e(beta_Y_p_r)[1,1] =  0.27552441      (= ΔY^+)
e(beta_Y_p_l)[1,1] = -0.02234708      (= ΔY^−)
差                 =  0.29787150
e(tau_cl)          =  0.29787150      ← 完全相等（差 0）
```

**结论**：`ΔY^±` 无需自造，直接取 `e(beta_Y_p_l/r)[1,1]`；且恒有 `ΔY^+ − ΔY^− ≡ e(tau_cl)`。

**裁决**：§6 的边界公式用**常规**估计量（论文 §3 的式 (4) `τ̂_p(h_n)`），即 `tau_cl` 与 `beta_Y_p_*`，**不用** `tau_bc`。

### 11.3 **`Lemma 1` 的等价性只在「固定同一带宽」下成立**（重要实现裁决）

实测（同一份数据）：

| 做法 | 带宽 | 结果 |
|---|---|---|
| `RD of ΔY`（各自选带宽） | h=0.2165 | **0.300031** |
| `RD(y1) − RD(y0)`（各自选带宽） | h 各不相同 | **0.290737** |
| `RD of ΔY`（强制 h=0.2165, b=0.3263） | 固定 | **0.30003137** |
| `RD(y1) − RD(y0)`（强制同一 h、b） | 固定 | **0.30003137** |

→ **`Lemma 1` 是总体层面的恒等式；有限样本下各回归的 MSE-最优带宽不同，会使两种参数化不相等。**

**设计裁决**：`didc` 同时报出两种参数化（`RD of ΔY` 与 `Δ of RDs`）作为 `Lemma 1` 的**内置自检**，且
**强制使用同一组 `h`/`b`**，从而二者应逐位相等；若用户手动指定了不同带宽则给出警告。

### 11.4 **识别集可以为空，且这是真实特征**（推翻 §9 的「排版错误」判断）

实测 `c1 = c2 = 0`：`LB = max{ΔY^+, τ} = 0.3000`，`UB = min{ΔY^+, τ} = 0.2755` → **`LB > UB`，集合为空**。

代数条件（**已修正**）：`LB > UB ⟺ ΔY^+ ≠ τ ⟺ ΔY^− ≠ 0`，**与 `ΔY^−` 的符号无关**。
含义：`A4`（`c_2 = 0`）与 `A6`（`c_1 = 0`）同时成立的子集要求 `ΔY^− = 0`；只要阈值左侧的结果也发生了变化（`ΔY^− ≠ 0`，正负皆可），两条限制就互相矛盾 → 无可行参数值。

> ⚠️ **重要推论**：`(c_1, c_2) = (0, 0)` 这一格**几乎总是空的**——真实数据的局部线性左截距不可能精确为 0。
> 所以「原点为空」**不等于**研究结论崩塌，它只说明 `A4` 不被数据支持。有经济意义的量是
> **breakdown value**（结论翻转所需的 `c_1`、`c_2`），`didc_bounds` 必须把它报在显眼位置。

对照论文 Table 8 的 `(6.33, −6.57)`：`LB = ΔY^+ − c_1` 随 `c_1` 递增而递减（6.33→1.33），
`UB = τ^DiDC + c_2` 随 `c_2` 递增而递减（−6.57→−5.57）——**与 `ΔY^+ = 6.33`、`τ^DiDC = −6.57` 完全吻合**，
故原文是正确输出，不是排版错误。这也与论文在 Taxes 上**拒绝** A4 的 Wald 结果一致（§8）。

**实现要求**：`didc_bounds` 必须支持并显式报告 `empty` 识别集，且把它解释为「数据与该组敏感度假设不相容」，
而非报错；同时输出 **breakdown value**（使 `LB` 跨过 0 的最小 `c_2`）。
