# didc（Difference-in-Discontinuities · Stata 包）Implementation Plan

> **For agentic workers:** 逐任务执行，用 `- [ ]` 勾选跟踪。每个任务先写测试、跑出失败、再实现、再跑通。
> Windows 本机执行方式：`Start-Process -FilePath "D:\Stata\StataMP-64.exe" -ArgumentList '/e','do',"<abs path>.do" -WorkingDirectory <dir> -Wait`，读 `<name>.log`。
> ⚠️ Stata 批量模式**遇错即停**，测试脚本里凡预期可能报错的命令一律前置 `capture`。

**Goal:** 实现一个正确、可用、有文档、可复现的 Stata 包 `didc`，把 Difference-in-Discontinuities（DiDC）的**估计 + 两条有效性检验 + 部分识别**在 Stata 生态里一次补齐。

**Architecture:** 三个用户命令（`didc` / `didc_test` / `didc_bounds`）+ 四个内部 ado。点估计与推断**委托 `rdrobust`** 对 `(ΔY, Z)` 执行（论文原做法），原创性集中在设计层、检验层、部分识别层。

**Tech Stack:** Stata 17+（本机 19.0 MP）、`rdrobust`（SSC）、Git/GitHub。测试用 `Start-Process` 驱动 headless Stata。

**Spec:** `didc/docs/specs/2026-09-30-didc-design.md`
**Research:** `didc/docs/research-notes.md`（估计量精确定义、假设、DGP、实测裁决）
**执行者三份都要读。**

## Global Constraints

- Stata **17+**（本机 19.0；`rdrobust` 在 19 上实测通过）
- 许可证：AGPL-3.0
- 包名 / 主命令名：`didc`；命令为 `didc`、`didc_test`、`didc_bounds`
- 依赖：`rdrobust`（`didc.pkg` 里声明 `requires rdrobust`；运行时用 `capture which rdrobust` 检查，缺失给可操作提示）
- 文档语言：README/sthlp **英文**；`docs/` 内部文档中文
- **点估计与稳健 CI 不得自造**，一律走 `rdrobust`；自造只允许出现在检验层与部分识别层
- 出口字面禁用「left/right」指代处理/对照——一律 `above cutoff` / `below cutoff`
- 估计量公式与假设以 `research-notes.md` 为准，禁止凭印象；凡偏离必须写进 `CHANGELOG.md`
- 所有随机过程（KS bootstrap）默认固定种子，保证无 `seed()` 也可复现

## Review Focus

以下是最容易让使用者踩坑、且**必须被测试覆盖**的点（括号内为覆盖任务）：

1. **处理组可能在阈值下方**（Grembi 案例即如此：人口 < 5000 才是处理组）。输出若写死「left = control」就是错的。（Task 4、Task 7）
2. **`ΔY` 方向**必须 `post − pre`；写反则所有符号翻转且不自检。（Task 3）
3. **带宽不一致会破坏 `Lemma 1` 等价性**：实测各自选带宽时 `RD of ΔY = 0.300031`，`RD(y1)−RD(y0) = 0.290737`；强制同带宽后二者**逐位相等**。自检必须固定同带宽。（Task 4，`research-notes.md` §11.3）
4. **`runvar` 时不变**：论文假设 `Z_i` 跨期不变。若同单位跨期取值不同，`ΔY` 的「阈值」失去意义，必须报错。（Task 3）
5. **边界必须用常规（conventional）估计量**，即 `e(tau_cl)` 与 `e(beta_Y_p_*)`，**不是** `e(tau_bc)`。依据：论文 §3 的式 (4) 是无偏误校正的 `τ̂_p(h_n)`。（Task 7）
6. **空识别集 `LB > UB` 是真实输出**（等价条件 `ΔY^− > 0`），不得报错。论文 Table 8 即如此。（Task 7，`research-notes.md` §11.4）
7. **KS 检验必须 recentered bootstrap**（原假设下重抽），且 `KS_−` 的求和下标按 `Z_i < z_0` 实现（论文印刷为 `≥`，与其 `S^−(Z)` 定义矛盾）。（Task 6，`research-notes.md` §9 item 2）
8. **无 `seed()` 也要可复现**：KS bootstrap 默认固定种子。（Task 6）
9. **`rdrobust` 缺失**时必须给「`ssc install rdrobust`」的可操作提示，而不是抛 `r(111)`。（Task 3）
10. **`didc_test` 的 `pre()` 至少两期**；只有一期时必须报错而非静默降级。（Task 5）

### Task 4: `didc.ado` —— 主估计（含 `Lemma 1` 内置自检）

**Files:**
- Create: `didc/didc.ado`（实现主体）
- Create: `didc/_didc_lpoly.ado`（`rdrobust` 薄封装，固定带宽参数）
- Create: `didc/_didc_display.ado`（结果表）
- Create: `didc/examples/_test_closedform.do`（V1）
- Create: `didc/examples/_test_confounder.do`（V2）

**Interfaces:**
- Consumes: `_didc_prep` 的 `build`
- Produces: 命令
```
didc depvar [if] [in], runvar() time() pre() post() [cutoff() p() q() kernel() bwselect() h() b() level() graph() nolemma1]
```
  返回 `e()`：见 spec §4.4（含 `e(dy_right)`、`e(dy_left)`、`e(tau_didc)`、`e(lemma1_ok)`、`e(tau_delta_of_rds)`、`e(bw_h_l/r)`、`e(bw_b_l/r)`）

- [ ] **Step 1: 写 V1 闭式单测**

```stata
* ΔY 每侧严格线性 + 常数跳跃 -> 局部线性应精确复原 tau，且与带宽无关
set seed 1
* y1-y0 = 0.4 + 0.8z + tau*(z>=0) + (eps1-eps0)
* 断言 |e(tau_didc) - tau| < 1e-10（注意：eps 会带来抽样误差 -> 用 eps 同分布但构造 dy 精确可加？
* 折中：令 eps1-eps0 精确为零不可行；改为断言 tau 的偏差 < 3*se 且带宽无关性：
*   固定 h1=0.2 与 h2=0.4 两次估计，差异 < 1e-8（线性下应完全一致）
```
> 实现前先把 V1 的「精确」标准定成**带宽无关性**（`h(0.2)` vs `h(0.4)` 结果逐位一致），
> 而不是「等于真值」——后者受抽样噪声影响。这是 V1 的可执行版本。

- [ ] **Step 2: 写 V2 混淆单测**

```stata
* 同一份数据上：
*   didc        -> 复原 tau
*   rdrobust y(t=post) -> 得到 cjs + tau
*   断言 |rdrobust_post - didc - cjs| < 3*se
```
- [ ] **Step 3: 跑 V1/V2，预期失败**（命令还是空壳）
- [ ] **Step 4: 实现 `_didc_lpoly`**（对 `(ΔY, Z)` 调 `rdrobust`，把 `e()` 原样透传）
- [ ] **Step 5: 实现 `didc` 主体**：
  1. `_didc_prep check` → `_didc_prep build dy zc`
  2. 主回归：`rdrobust dy zc, c(0) p() q() kernel() bwselect()`
  3. `e(dy_right) = e(beta_Y_p_r)[1,1]`，`e(dy_left) = e(beta_Y_p_l)[1,1]`
  4. `e(tau_didc) = e(dy_right) - e(dy_left)`；断言 `== e(tau_cl)`（差 >1e-10 则内部报错）
  5. **Lemma 1 自检**：取主回归的 `h_l/h_r/b_l/b_r`，强制同一组带宽，分别跑 `dy`、`y_post`、`y_pre` 三个 `rdrobust`，
     断言 `RD(dy) == RD(y_post) - RD(y_pre)`（≤1e-10）；存 `e(lemma1_ok)` 与 `e(tau_delta_of_rds)`
  6. 用户手动指定 `h()`/`b()` 且左右不同时，`nolemma1` 或给 warning
- [ ] **Step 6: 跑 V1/V2，预期通过**
- [ ] **Step 7: V3 对照 R `rdrobust`**
  - Create: `didc/examples/reference/run_rdrobust.R`、`didc/examples/_test_vs_rdrobust.do`
  - Stata 侧导出 `(dy, z)` 为 CSV → R 侧 `rdrobust(y=dy, x=z, c=0, p=..., q=..., kernel=...)` → 存参考 CSV
  - 断言点估计、`se_tau_rb`、`ci_l_rb`、`ci_r_rb` 全部 **≤ 1e-6**
  - ⚠️ 带宽必须两边一致：R 侧传 `h=`/`b=`（用 Stata 的 plug-in 值），否则选择器差异会误判

```stata
* Y_i = a_i + sum_k [ beta_-k (Z-z0) + theta_-k D_i (Z-z0) ] T_-k + eps_i
* 等价实现：pooled OLS with i.T#c.(Z-z0) 与 i.T#i.D#c.(Z-z0)

```
