## 1. 目标

v1 把点估计、带宽选择、偏误校正与稳健方差全部委托给 `rdrobust`（论文本身的做法）。
这保证了正确性，但把「估计核」这一层留给了外部依赖。v2 的目标是**把这层变成自己的**，
同时不放弃 v1 唯一真正的护城河：**与权威实现逐位对齐的能力**。

用户明确要求：「如果希望估计核也自造……做完后提醒我可以后续改进把這個加进去」，
并在 2026-09-30 指示「v2 自造估计核繼續做吧」。

## 2. 核心设计判断

### 2.1 估计量是 Y 的线性泛函

这是整个 v2 的关键观察。局部多项式估计、偏误校正、以及二者的任意线性组合，**全都是
已知权重下的线性泛函**：

```
mu_hat_s = w_s' y_s          （w_s 由设计矩阵与核权重显式给出）
tau_bc   = w_+' y_+ - w_-' y_-   （偏误校正只是把 w_s 减去一个已知倍数的高阶导数权重向量）
```

因此：

- **点估计**就是加权最小二乘，无需任何渐近理论；
- **方差**可以直接用权重算出来，而且对固定设计是**精确**的：
  `Var(tau) = sum_s s2_s * sum_i w_si^2`。

这条路径**绕开了 CCT 的闭式渐近方差代数**——那是 v1 里唯一没人能独立验证的部分。

### 2.2 但要诚实承认两处不能对齐

**（一）方差约定不同。** `rdrobust` 默认用**最近邻**估计 `σ²` 并用 CCT 的渐近方差；
本引擎用残差估计 `σ²` 并算**精确有限样本方差**。两者都随样本量收敛到同一个极限。实测
（模型 1，n=1000，150 次重复）：

| 引擎 | `se_rb` 与 `rdrobust` 之比 | 95% 区间覆盖率 |
|---|---|---|
| `engine(rdrobust)` | 1.00 | 0.960 |
| `engine(mata)` | **0.94** | **0.953** |

> **v0.2.1 修正**：v0.2.0 曾测得比值 0.83、覆盖率 0.920。那不是方差约定造成的，而是
> **一个真 bug**：稳健方差的权重向量漏掉了 `1/b^{p+1}` 尺度因子（该因子在原子里抵消、
> 在方差里不抵消）。补上后比值 0.94、覆盖率 0.953。**教训**：这种「点估计正确、只有
> 方差错」的错误不会被点估计的逐位比对发现，必须靠覆盖率检验——所以
> `examples/_test_engine.do` 现在每次运行都打印这两个数作为回归哨兵。

现在的差距（0.94 与 0.953 vs 0.960）来自两套 `σ²` 估计约定（最近邻 vs 残差），差异在
蒙特卡洛误差内。因此默认仍是 `engine(rdrobust)`——理由已从「mata 不准」变成「rdrobust 是
参考实现、逐位等同于已发表结果」。

> 曾尝试反解 `rdrobust` 隐含的 `σ²`（用 `se_cl²` 与 `se_rb²` 两个方程解两个未知量），
> 但方程组病态、解出负方差，**说明其稳健方差不是两个单侧方差的加权和**，而是 CCT 的
> 闭式表达，含额外的偏误估计方差项。要逐位复现必须把那套代数抄回来——那是 v2b 的范围。

**（二）`p ≥ 2` —— v0.2.1 已修复。** v0.2.0 时 `p(2)` 的偏误校正与 `rdrobust` 差 `6e-04`，
当时的推测是「CCT 用理论核矩」。**推测是错的**，真实原因是我自己在 `Bconst` 上多乘了一个
`factorial(p)`：

```
偏误 = h^{p+1} · [e₀'Γ⁻¹ϑ_{p+1}] · μ^{(p+1)}(0)/(p+1)!     （无额外常数）
     = h^{p+1} · [e₀'Γ⁻¹ϑ_{p+1}] · β_{p+1}/b^{p+1}          （(p+1)! 抵消）
```

`factorial(1) = 1`，所以 `p(1)` 的 1e-16 对齐**完全看不见**这个错误；`p(2)` 时它把偏误放大了
一倍。同时下侧的定向符号 `(-1)^{p+1}` 也是多余的（`(-1)² = 1`，同样在 `p(1)` 隐藏）。
去掉这两者后，`p(2), q(3)` 下两个引擎在六项上一致到 **8.3e-16**。

**教训**：点估计的逐位比对只能验证点估计。这两个 bug 一个是方差错误、一个是高阶偏误错误，
**只有覆盖率检验和对 `p ≥ 2` 的检验能发现它们**。因此 `examples/_test_engine.do` 现在
每次运行都跑 `p(2)` 并打印覆盖率与标准误之比。

## 4. 验证（实跑结果）

**逐位对齐**（`examples/_test_engine.do`，同一组 h/b/核/p/q）：

| 设定 | `tau_cl` | `tau_bc` | 六项最大偏差 |
|---|---|---|---|
| `p(1) q(2)` 三角核 `h(0.4) b(0.6)` | 0.299145402132 = 0.299145402132 | 0.290665021109 = 0.290665021109 | **2.78e-16** |
| `p(1) q(2)` 均匀核 `h(0.4) b(0.6)` | 0.315117327955 = 0.315117327955 | 0.313471507341 = 0.313471507341 | **5.00e-16** |
| `p(2) q(3)` 三角核 `h(0.5) b(0.8)` | 0.285822692445 = 0.285822692445 | 0.279464932384 = 0.279464932384 | **8.33e-16** |

比较的六项：`tau_cl`、`tau_bc`、`mu_plus`、`mu_minus`、两侧偏误。
`p(2)` 单看两侧偏误的最大偏差为 `1.30e-15`；下侧偏误 `−0.001439927893` 与 `rdrobust` 相同。

**多项式阶**：`p(2)`（v0.2.1 起）被接受且与 `rdrobust` 一致。

**稳健标准误之比**：0.9406 / 0.9641 / 0.9218（三角 `p1` / 均匀 `p1` / 三角 `p2`）。
**覆盖率**：模型 1、n=1000、150 次重复、τ=0 → mata **0.9533**、rdrobust 0.9600。

> v0.2.0 曾测得比值 0.83、覆盖率 0.920；根因是方差权重缺失 `1/b^{p+1}` 因子（见 CHANGELOG）。

## 5. 剩余工作（v2b）

1. ~~**让 mata 的方差追上覆盖率。**~~ **已完成（v0.2.1）**：根因不是方差约定，而是权重向量
   缺失 `1/b^{p+1}` 因子。修正后覆盖率 0.9533，与 `rdrobust` 的 0.9600 之差在 MC 误差内。
   残留的 0.94 标准误比值来自 `σ²` 约定（最近邻 vs 残差），若要彻底消除需实现最近邻估计器。
2. ~~**`p ≥ 2` 的偏误校正。**~~ **已完成（v0.2.1）**：根因不是核矩，而是多乘的 `factorial(p)`
   与多余的定向符号。修正后 `p(2)` 与 `rdrobust` 一致到 8.3e-16，限制已解除。
3. **自造带宽选择器**（`mserd` / `msetwo`）：目前仍委托 `rdrobust`。需要实现 CCT 的
   plug-in 规则：导数的 pilot 估计、`σ²` 与密度 `f` 的估计、以及各阶核矩常数。
   完成后 `engine(mata)` 才真正不依赖任何外部包。
4. **`design(rcs)` 支持 mata 引擎**（目前 rcs 分支仍走 `rdrobust`）。
5. **三路互验**：自造核、`rdrobust`、手写 WLS（`examples/_test_vs_wls.do`）三者并存，
   作为发布前的固定回归。
